## 送信のしくみ

ファンクラブLPと**同じウェブアプリURL1本**へ送ります。行き先は、このフォームが送る
`form=english` を見て Apps Script 側が振り分けます（`28_本番フォーム_GAS_20260819.gs` の §英語教室）。
デプロイを分けるとURLも権限の承認も2つになり、あゆな様の手元が増えるためです。

1件届くと次の3つが動きます。

1. 申込一覧「公式LINE 英語教室 申込一覧（紫あゆな）」に1行
2. `Ayuna.8.mu@gmail.com` へ「○○さんの受講お申し込み」のお知らせ
3. お申し込みくださった保護者の方へ、受付の自動返信

**曜日・時間・場所・費用の案内は自動では送りません。**「あらためてご連絡します」とお伝えする形なので、
お知らせを受けたあゆな様から保護者の方へご連絡いただく前提です。お知らせメールにもその旨を書いてあります。

## 公開するときの順番（守らないと名簿が汚れます）

**GASを先に新しくしてから、このページを公開します。**

1. `Ayuna.8.mu@gmail.com` の Apps Script「紫あゆな 公式LINE フォームとファンクラブ受付」を開く
2. `28_本番フォーム_GAS_20260819.gs` の全文を貼り替える
3. **デプロイを管理 → 鉛筆 → バージョン=新バージョン → デプロイ**（この手順ならURLは変わりません。
   「新しいデプロイ」を選ぶと別URLになり、ファンクラブLPも直すことになります）
4. `setupEnglishReceiver` を実行 → 申込一覧ができ、当方へ編集者共有される
5. `testEnglishReceiver` でメール2通を確かめる（テスト行はあとで消す）
6. このリポジトリを上げて GitHub Pages を有効にする
7. 公開ページから1件送って、申込一覧・お知らせ・自動返信の3つを確かめ、テスト行を消す

古いバージョンのまま先に公開すると、`english` の振り分けが無いため、
**ファンクラブの名簿へ中身の欠けた行が入ります。**

## フォームが送る項目

`form`（`english` 固定）/ `childName` / `childAge` / `school` / `experience` /
`parentName` / `parentKana` / `email` / `tel` / `source` / `message` / `submittedAt`

必須は `childName` `childAge` `experience` `parentName` `parentKana` `email` `source` の7つです。
`school` `tel` `message` は任意にしてあります。

`source` は「このページをどちらでご覧になりましたか」の回答です（公式LINE ／ ホームページ ／ SNS ／ その他）。
リッチメニューから `?from=line` を付けて開くと、公式LINEがあらかじめ選ばれた状態になります。
ホームページから貼るときは `?from=hp` を付けてください。

`website` という欄がHTMLにありますが、これは人に見えない位置に置いたボット除けです。
ここに文字が入っている送信は、機械によるものとして捨てています。

## 送信のしかた

`application/x-www-form-urlencoded` で送っています。独自のヘッダを付けないので、
ブラウザが送信前に別の問い合わせ通信（preflight）をせず、Apps Script の `e.parameter` でそのまま読めます。

お返事だけが読めなかったときのために、`mode: "no-cors"` でもう一度だけ送り直します。
そのとき `submittedAt` は最初と同じ値を送るので、受け側が同じお申し込みだと判断し、
申込一覧が2行に増えることはありません。

## 直すとき

`index.html` を書き換えて push すれば、1分ほどで公開ページに反映されます。
検査台が案件フォルダの `gas/英語教室_設置記録_20260830/` にあります。直したら

```
node test-english-gas.mjs    # GASの受け口（GASのAPIをスタブして54項目）
node check-english-lp.mjs    # LPの入力欄とGASの受け口の突き合わせ（53項目）
node serve-english-lp.mjs    # ローカルで通し確認（送信先はローカルへ差し替わる）
```

の順に通してから上げてください。
